# Objective 34D — opt-in text-only tab recovery (OFFLINE)

This is a convenience preview cache in browser `sessionStorage`, scoped to the same origin and tab. It is **off by default**. Selecting the checkbox opts in to a 30-minute rolling recovery snapshot; closing the tab normally discards the tab-scoped cache. A separate Restore button requires a customer click and confirms before replacing existing work. A Forget button removes the cache. Reset clears it. No `localStorage`, cookies, network calls, production database, background service worker, or Shopify API are involved.

Only a bounded product ID, conceptual options, surface, and validated text-layer geometry are stored. No bearer owner tokens, saved references, grants, artwork bytes, GLB files, calibration measurements, price, cart, or order metadata are serialized. If the editor contains imported GLB, artwork, grants, or calibration, the checkbox opts out and clears the prior cache rather than offering a misleading partial restore. Cache entries are untrusted: exact schema, expiry, product/surface/options, text layer bounds and composition geometry are revalidated. Tampering cannot authorize manufacturing or checkout. Browser sessionStorage is not encrypted; avoid entering sensitive text into the opt-in preview cache. Users must use the existing private recovery-receipt workflow to recover local-server drafts with artwork (and keep the receipt secret).

**Gates:** Actual browser acceptance remains outstanding, as do hosted auth, durable customer storage, private artwork lifecycle, Shopify integration, pricing, and manufacturing approval. This does not guarantee recovery after browser crash, browser policy denial, or device loss.
