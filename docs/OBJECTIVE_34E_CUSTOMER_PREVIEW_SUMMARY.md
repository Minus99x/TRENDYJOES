# Objective 34E — product selection → editor → validated preview summary

**Local prototype only. No Shopify writes, hosted service, cart, order, payment, price or manufacturing approval.**

From the existing `/demo/start.html` concept gateway, choose any of seven product families. The `/demo/?product=<manifestId>` link selects the manifest; existing editor tools customize text, artwork, concept colors/sizes, surfaces, and 2D/3D views. The new **Review my design · preview only** button builds a strict, ephemeral, allowlisted summary of the current editor state. It requires a known product/surface, valid options, at least one geometrically valid layer, and locally present private artwork handles for any artwork layers. It rejects stale/forged product and surface selections, invalid transforms, duplicate layer IDs, missing artwork, and unrecognized option values.

The summary displays only safe product/option labels, surface names, element counts, local saved-revision state, and explicit production/commerce blockers. It never serializes layer text, artwork IDs/bytes, local owner bearer tokens, design reference, Shopify variant IDs, GLB bytes, or measurement worksheets. It uses `textContent` exclusively for DOM projection; no query string, `localStorage`, server write, export or cart line is generated. Changes to the editor (including color, size, layer, product, recovery and local save) invalidate and hide the prior review. Return to editor restores focus. This is **not** an authenticated security decision; the backend must independently verify everything for any future hosted flow.

Validation: `node --test tests/objective34e-preview-design-summary.test.mjs`, then `npm test`. Native Shopify theme preview and actual interactive browser acceptance remain Main Engineering gates; local HTTP smoke is not equivalent to hosted acceptance. The review is intentionally usable with an unsaved design but labels it **UNSAVED PREVIEW**; a local saved revision is marked current only when the full editor snapshot still matches. It never claims a production draft or purchase.
