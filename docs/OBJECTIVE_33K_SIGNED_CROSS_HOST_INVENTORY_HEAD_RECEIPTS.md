# Objective 33K — offline signed inventory-head receipt reconciliation

**Scope:** Universal Custom Design & 3D Product Studio only. Read-only offline contract; **no Shopify reads/writes** and no deployment.

`src/offline-conflict-adjudication-inventory-head-receipts.mjs` defines an Ed25519-signed, domain-separated, bounded, canonical receipt for a claimed Objective 33J append-only adjudication-inventory head. It is not a network client and never reads another host's disk. A host signs the bytes from `offlineConflictInventoryHeadReceiptBodyBytes(body)` externally; the signed receipt is canonical UTF-8 JSON bytes `{body,signature}`. The body binds 33J inventory schema, namespace, journal scope, host ID, deterministic 33J genesis head, claimed inventory head, observation/expiry window (<=10 min), and nonce. This code does not manage private keys.

`offlineConflictInventoryHeadReceiptDigest(bytes)` returns a domain-separated SHA-256 digest for independent custody. `reconcileOfflineConflictInventoryHeadReceipts({receipts,hostPins,expectedNamespaceId,expectedJournalScopeDigest,expectedGenesisHead,nowMs,seenDigests,seenNonces})` requires 2–8 host receipts in sorted host-ID order with a complete independently pinned roster, **unique Ed25519 public keys**, per-host independently retained receipt digests **and claimed inventory heads**, a caller-retained genesis pin, and optional caller-retained replay sets. Missing/extra hosts, signatures, wrong key, malformed/noncanonical bytes, duplicate nonces, stale time, replay, scope substitution and head mismatch fail closed.

The verifier returns one of three strictly limited outcomes: `consistent-head` (all signed head claims identical), `conflicting-same-height` (different signed digests at equal counts), or `unresolved-different-heights` (different counts, no ancestry proof). An evidence digest binds the ordered raw signed receipts for later independent retention. No outcome proves disk contents, a global fork, global completeness, chronological precedence, independent timestamps, network authenticity, immutable external publication, or consensus. Caller-provided pins are only independent if obtained and retained via a separate trusted channel; a malicious caller can self-pin fabricated claims. Replay sets are **not durable** and do not replace Objective 33J's local durable journal. No auto-repair, authorization, checkout or production action.

**Adversarial tests:** `node --test tests/objective33k-cross-host-inventory-receipts.test.mjs`. Covers forged signature with repinned digest, same-height split views, unequal-height ambiguity, omitted and extra host, key reuse, replay, scope substitution, head tamper, noncanonical JSON, duplicate keys, malformed UTF-8, expiry and invalid genesis.

**Remaining gates:** trusted independent host identity and key custody, actual remote acquisition, independent time, published immutable trust anchors, independent disk-state witness, durable multi-host replay admission, verified cross-host ancestry, globally consistent history, hosted authentication, and distributed atomic recovery. No live Shopify checkout, orders or production readiness.
