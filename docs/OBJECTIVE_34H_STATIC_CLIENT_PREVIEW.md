# Objective 34H — Static, ephemeral Design Works customer preview

**Offline-only integration candidate. Not Shopify-installed. Not production-ready.**

`demo/static-preview.html?product=concept-rug` provides a working client-only product selection → 2D/3D conceptual preview → text editing → redacted non-purchasing review. It imports the existing product catalog, composition validation, concept options, procedural 3D renderer and preview-summary projection. It does **not** depend on the loopback API.

Run `npm run serve` and open `http://127.0.0.1:8000/demo/static-preview.html?product=concept-rug`. Or host the static asset graph under one origin, retaining the module-relative paths. The static asset manifest is at `integrations/shopify/static-preview-asset-manifest.json`; validate it with `npm run preview:static:assets:check`. This is an integrity inventory, **not** a deployable Shopify theme bundle. The source `demo/studio.mjs` remains a separate local-server-only editor with full private draft, GLB and calibration tools; none of those capabilities are removed or claimed to work in the static candidate.

**Security and usability boundaries:** CSP `connect-src 'none'` and `form-action 'none'`; no `fetch`, cookies, storage, network upload, authentication, artwork/GLB import, saved drafts, prices, cart or checkout in the static dependency graph. Ephemeral state exists only in JS memory and is discarded on refresh. The seven conceptual product families are extensible via the existing manifests. Switching products with work requires confirmation. Layer placement is validated against conceptual normalized zones. Review uses an allowlisted projection and invalidates on edits. Color/size/3D remain illustrations, not real SKUs or calibrated production models. No manufacturing approvals or real orders are generated.

**Main Engineering integration instructions:** inspect the manifest's actual file graph, adapt module paths to Shopify asset URLs and verify CSP behavior in a real staging browser; do not simply copy the loopback editor or enable a link until actual staging route, browser interactions and privacy gates pass. Test 390/768/1440 widths, keyboard focus, 2D/3D, all seven product types, refresh discard, confirmation, no network traffic and no checkout. If a hosted private save, artwork upload or authentication is required, design a separately authorized secure backend; do not silently enable local-server endpoints. The published Horizon theme, real products and checkout remain untouched.
