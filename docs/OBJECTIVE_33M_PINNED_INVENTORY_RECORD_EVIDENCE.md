# Objective 33M — Independently pinned 33J record bytes and nested signed evidence

**Offline verifier only.** `src/offline-conflict-adjudication-inventory-record-evidence.mjs` consumes two independently pinned Objective 33K Ed25519 host-head receipts, 1–32 consecutive canonical Objective 33J record byte buffers from the longer asserted history, and an independently retained digest + predecessor/successor head pin for **every** supplied record. It does not contact or inspect a host.

`verifyOfflineConflictInventoryRecordEvidence({receiptArgs, records, recordPins})` first revalidates both host receipts, namespace, journal scope, signing keys, externally supplied receipt digests, genesis and signed head commitments. Equal signed heads return `consistent-signed-heads`; same-height divergent signed heads return `conflicting-same-height`. Missing record bytes return `unresolved-no-record-evidence`, while gaps above 32 return `unresolved-gap-exceeds-bound`; neither is accepted as ancestry.

For unequal heights, every supplied record must be canonical UTF-8 JSON, have exact 33J schema/field order and index, valid original `TJ-33J-INVENTORY-RECORD` body hash, independently pinned raw-byte digest under `TJ-33M-PINNED-INVENTORY-RECORD-BYTES`, and a predecessor matching the prior externally pinned head. The final reconstructed head must equal the independently pinned longer-host receipt. Every embedded 33I observer transcript is rehydrated from canonical base64url, checked against its original externally supplied identity, owner/scope and approval pins, and cryptographically reverified: observer Ed25519 signature, two-of-three Ed25519 approvals in each of two distinct reviewer groups, consistent independent observer assertions, acceptance-time validity, and replay uniqueness across supplied records. Recorded acceptance times must not exceed the externally supplied current time or longer-host receipt observation time.

A valid result is `verified-pinned-record-suffix`: **only** the supplied suffix bytes and their nested signatures have been verified. It does **not** prove that the records were ever written to or persisted on the remote host, that the earlier prefix is valid, that the signing keys were protected, that pins were actually published independently, or that host time is trusted. It does not grant repair, recovery, manufacturing, cart, checkout, order, deployment, or production authority. No files, Shopify resources, customer data, or external services are accessed by this module.

Reproduce focused tests: `node --test tests/objective33m-pinned-inventory-record-evidence.test.mjs`. Full regression: `npm test`. Fixtures use freshly generated local Ed25519 keys and genuine signed 33H reviewer decisions / 33I observer transcripts, nested in canonical 33J records and two signed 33K receipts; no real customers, keys, or hosted authentication.
