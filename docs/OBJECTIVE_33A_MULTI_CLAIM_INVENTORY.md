# Objective 33A — externally pinned multi-claim inventory and cross-observer reconciliation

**Local, read-only, opt-in prototype.** This module extends Objective 32Z (single-claim continuity) to a bounded inventory of interrupted manifest claims within an **externally designated journal scope**. It never mutates journals, repairs pending claims, creates external witnesses, or authorizes checkout, printing, orders, or production.

`src/offline-conflict-manifest-multi-claim-inventory.mjs` exports:

- `calculateOfflineConflictManifestMultiClaimInventory({journalScopeDigest,claims})`: computes a **candidate** digest. `claims` is 1–32 objects `{entries,expectedHead}`; each entry is a complete Objective 32Y signed transcript with all its independently retained verification pins. Each claim is reverified through Objective 32Z. Claim identity is derived from its authenticated prior journal head, pending index/record/byte digests, and reviewer policy digests. Claims are canonically sorted by identity. Two distinct pending records at the same prior head/index within one asserted scope are rejected as a fork. Repeated claim identities are rejected, even if their transcript chains differ.
- `verifyOfflineConflictManifestMultiClaimInventory({journalScopeDigest,claims,expectedJournalScopeDigest,expectedInventoryDigest,expectedClaimCount})`: verifies against **separately retained** exact scope, inventory digest, and count. A candidate digest recomputed from the untrusted input is **not** an independent pin.
- `calculateOfflineConflictManifestMultiClaimReconciliation({journalScopeDigest,observations})`: candidate reconciliation for 2–8 observers, each `{observerId,claims,expectedInventoryDigest,expectedClaimCount}`. Observer identities must be distinct. Each observer inventory is cryptographically reverified. The verifier rejects omitted/different claim sets and any disagreement on a claim's pinned continuity checkpoint or last observed state. Ordering of observers and claims does not affect the candidate digest.
- `verifyOfflineConflictManifestMultiClaimReconciliation({journalScopeDigest,observations,expectedJournalScopeDigest,expectedReconciliationDigest,expectedObserverCount})`: requires an independently retained reconciliation digest, scope and observer count.

**Adversarial behavior:** missing/forged per-claim signatures, altered transcripts, wrong independently retained heads, same-slot forks, duplicate claims/observers, missing claims, concurrent unequal checkpoints, observer equivocation, count/pin substitution, oversized/sparse/accessor-bearing arrays and malformed identities all fail closed. A legitimate concurrent extension with different checkpoint counts also fails closed until independently reconciled; timestamps are not trusted ordering evidence.

**Critical limits:** `journalScopeDigest` is a caller-provided namespace pin and **is not cryptographically bound into the earlier 32Y signed transcripts**. The caller must establish the namespace mapping independently. Neither the observer names nor the digest pins are themselves signed or published by this module. Matching supplied inventories cannot prove that all historical claims or observers were included; a colluding set can omit the same item from every supplied inventory unless an independently preserved earlier inventory commits to it. No global consensus, monotonic trusted clock, offsite anchoring, protected reviewer signing keys, hostile privileged filesystem protection, hosted identity, or production integration exists.

Reproduce offline on Node 22.16.0: `node --test tests/objective33a-multi-claim-inventory.test.mjs` then `npm test`. Test data uses synthetic Ed25519 reviewers and local temporary journal fixtures only. No Shopify reads or writes.
