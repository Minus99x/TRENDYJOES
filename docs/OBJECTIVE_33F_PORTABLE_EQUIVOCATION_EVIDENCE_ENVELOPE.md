# Objective 33F — Portable, pinned equivocation evidence (offline)

This objective adds `src/offline-conflict-authority-equivocation-envelope.mjs` to export and independently verify **read-only evidence of two valid but conflicting signed authority-policy histories**. It builds directly on Objective 33E and recursively verifies 33D → 33C → 33B → 33A → 32Z/32Y, including signed interrupted-claim evidence.

## Format and interface

`exportOfflineConflictAuthorityEquivocationEnvelope({reconciliationArgs, nonce, issuedAt, expiresAt, previousEnvelopeDigest})` refuses consistent or prefix-extension histories. It copies input defensively, verifies both signed histories, then exports bounded JSON bytes containing exact cryptographic signed objects, complete histories, signed fork snapshots, a previous-envelope digest, namespace/scope binding, two observer IDs, attestation digests, chain heads, and a bounded validity window. Byte buffers are represented as canonical base64url, public Ed25519 key objects as canonical SPKI DER/base64url; private keys are rejected. It returns a domain-separated SHA-256 digest of the exact bytes for **independent custody**. Max size: 2 MiB; no network writes.

`verifyOfflineConflictAuthorityEquivocationEnvelope({bytes, expectedDigest, expectedNonce, expectedPreviousEnvelopeDigest, expectedNamespaceId, expectedJournalScopeDigest, expectedObserverIds, expectedAttestationDigests, expectedChainHeads, seenEnvelopeDigests, nowMs})` fails closed if external pins are absent or inconsistent. It checks byte limits, domain-separated digest, caller-supplied replay history, strict UTF-8, canonical JSON (duplicate keys, whitespace, alternate encodings and trailing content rejected), validity window, typed encoding, externally pinned observer identities and heads, and **recursively re-verifies both signed histories and the exact fork evidence**. Signed JSON body property order is intentionally preserved because existing Ed25519 signatures cover exact `JSON.stringify` bytes; changing property order breaks signature verification. The envelope digest protects the complete byte representation.

## Adversarial regression

38 new `33F` tests appended to `tests/objective33e-authority-observer-reconciliation.test.mjs` use the existing full signed nested interrupted-claim fixtures. They cover valid portable verification; signed nonfork rejection; forged observers; missing/expired pins; nonce, namespace, scope, previous digest, observer ID/digest/head substitution; external replay rejection; malformed/duplicate-key/noncanonical JSON, invalid UTF-8, truncation and oversized envelopes; evidence omission/substitution; signed-history tampering and omitted transitions; fork-index manipulation; typed-wrapper injection; sparse replay history; prototype/accessor attacks; and absence of production authority. To focus on new cases: `node --test --test-name-pattern='^33F' tests/objective33e-authority-observer-reconciliation.test.mjs`.

## Security boundaries and unresolved gates

The verifier **cannot publish or independently witness** pins, guarantee an immutable previous-envelope chain, enforce global replay uniqueness, prevent an attacker from re-pinning all external evidence, establish global observer completeness, provide a trusted clock, or make either fork canonical. `seenEnvelopeDigests` must be durably maintained by an external authorized caller; an empty history on every invocation provides no persistent replay protection. `nowMs` is caller-supplied and is not trusted wall-clock evidence. It does not authorize repair, settlement, production, customer identity, Shopify checkout, or deployment. No Shopify reads or writes were performed. Main Engineering's unpublished staging and live theme remain untouched.
